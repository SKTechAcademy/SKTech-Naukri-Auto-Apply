# SK Tech Candidate Workspace

Manage separate candidates, technologies, resumes and Naukri sessions through one local dashboard.

Double-click **START-AUTO-APPLY.cmd** and open **http://127.0.0.1:8788**.

See [AUTO-APPLY.md](AUTO-APPLY.md) for candidate setup, account verification, isolation controls, migration details and current limitations.

Run `npm test` from `worker/` to check the application and isolation tests.
